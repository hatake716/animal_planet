# プライバシーポリシー / Privacy Policy

「地球儀で見る絶滅危惧種生物図鑑」(以下「本アプリ」)のプライバシーポリシーです。

## 収集する情報

本アプリは、**利用者の個人情報を収集・送信しません**。

- 既読の記録、ブックマーク、最後に見ていた地球儀の位置は、**利用者の端末内のみ**に保存されます(Android の DataStore / SharedPreferences)。外部サーバーへ送信せず、Android のクラウドバックアップの対象にもしていません(`allowBackup=false`)。
- アカウント登録、氏名・メールアドレス・位置情報・連絡先などの取得は行いません。
- 広告 SDK・解析 SDK(トラッキング)を組み込んでいません。

## 通信

本アプリは次の目的でインターネットに接続します。いずれも利用者の操作(種を選び記事・動画・写真の出典ページを開く)に応じて行われます。

- **Wikipedia**(日本語版・英語版)の記事表示(アプリ内ブラウザ)。
- **YouTube** の検索結果表示(アプリ内ブラウザ)。
- **Wikimedia Commons** の写真の出典ページ表示(アプリ内ブラウザ)。

これらのページの読み込みは各サービス(Wikimedia Foundation / Google)のサーバーとの通信であり、それぞれのプライバシーポリシーが適用されます。本アプリ自体が利用者を識別する情報を送ることはありません。

地球儀の画像(NASA Blue Marble)と各種の写真・解説はアプリに同梱しており、図鑑の閲覧そのものに通信は発生しません。

## 権限

- `INTERNET`: 上記の記事・動画・出典ページをアプリ内ブラウザで表示するために使用します。

## データの削除

既読・ブックマークは端末内にのみ保存されるため、アプリをアンインストールするか、Android の設定からアプリのデータを消去すると完全に削除されます。
