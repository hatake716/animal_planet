# Google Play 公開の準備チェックリスト

このアプリを Google Play で(有料アプリとして)公開するための、ストア掲載情報とコンプライアンスのまとめ。
**提出用の一式(手順書・掲載文・申告フォームの回答・グラフィック・スクリーンショット)は [`docs/play/SUBMISSION.md`](play/SUBMISSION.md) にまとめてあります。**

## 現在の状態

| 項目 | 状態 |
|---|---|
| ビルド形式 | 署名済み AAB(`./gradlew bundleRelease`) |
| バージョン | versionCode 3 / versionName 1.0.2 |
| 署名 | ローカルのアップロード鍵(`animal-planet-release.jks`、`.gitignore` 済み)|
| applicationId | `io.github.hatake716.endangeredglobe`(**公開後は変更不可**。第三者の商標を含まない中立な名前にしている。変更するなら初回公開前に) |
| compileSdk / targetSdk | 36 |
| minSdk | 30(Android 11 以上)|
| R8 縮小・リソース縮小 | 有効 |
| 権限 | `INTERNET` のみ |

AAB は `app/build/outputs/bundle/release/app-release.aab`。これを Play Console にアップロードする。
Play App Signing を使う場合、このローカル鍵は「アップロード鍵」として登録する(**鍵は紛失厳禁**)。

## ストア掲載情報(記入する内容)

- **アプリ名**: 地球儀で見る絶滅危惧種生物図鑑
- **カテゴリ**: 教育
- **簡単な説明(80 字以内)**:
  > リアルな地球儀に絶滅危惧種の生息地をピン表示。写真と解説、Wikipedia と動画をアプリ内で。
- **詳しい説明**:
  > リアルな 3D 地球儀の上に、IUCN レッドリストで絶滅のおそれがあると評価された動物 1,063 種(哺乳類・鳥類・爬虫類・両生類・魚類・無脊椎動物)を、代表的な生息地へピンとして配置しました。
  >
  > ・ピンをタップすると、写真・IUCN カテゴリ(CR / EN / VU)・分類・生息地・解説・主な脅威が表示され、Wikipedia の記事と、その種で検索した YouTube 動画をアプリ内で開けます。
  > ・生物の分類(哺乳類・鳥類・爬虫類・両生類・魚類・無脊椎動物)と生息地(日本・東アジア・ヨーロッパ・アフリカ・海洋など)で絞り込み。見たい項目だけチェックして表示できます。
  > ・全種の一覧を分類順・五十音順・危機度順で表示し、一覧の中を検索できます。一度開いた種には既読マークが付き、ブックマークもできます。
  > ・地図画像・写真・解説はアプリに同梱しているため、図鑑の閲覧はオフラインでも動きます。
  >
  > 写真は Wikimedia Commons の自由ライセンス画像(作者・ライセンスをアプリ内に表示)、解説は Wikipedia、分類と評価は Wikidata、地図画像は NASA Blue Marble(パブリックドメイン)です。
- **スクリーンショット**: `docs/play/screenshots/01_globe.png` 〜 `07_filtered.png`(1080×2160。Play の規則「最大辺は最小辺の 2 倍以下」に合わせたサイズ。`docs/images/` の 1080×2400 は README 用)。
- **アイコン**: `docs/play/icon_512.png`(512×512)。
- **フィーチャーグラフィック**: `docs/play/feature_1024x500.png`(1024×500)。

## 有料アプリの設定
- Play Console の「収益化 → 商品 → アプリの価格」で有料に設定し、販売国と価格を決める(無料→有料の変更は後からできないため、最初に有料で公開する)。
- 支払いプロファイル(販売者アカウント)の登録が必要。

## データセーフティ(Data safety)の記入

- **データの収集: なし**。個人情報・識別子・位置情報・利用状況を収集・送信しない。
- **データの共有: なし**。
- 既読・ブックマークは端末内(DataStore)にのみ保存され端末外に出ないため「収集」に該当しない。
- Wikipedia / YouTube / Wikimedia Commons のページはアプリ内ブラウザで表示するため、その閲覧は各サービスへの通信になる旨を「アプリの機能」欄で説明できる。

## プライバシーポリシー

- `docs/PRIVACY.md` の内容を GitHub Pages(`https://hatake716.github.io/animal_planet/PRIVACY/`)で公開し、その URL を Play Console に登録する
  (リポジトリの Settings → Pages → Deploy from a branch: `main` / `/docs`)。

## コンテンツのレーティング

- 暴力・性的表現・ギャンブル等なし。コンテンツ自体は全年齢向けだが、**対象ユーザー層は 13 歳以上**を選ぶ(YouTube の検索結果をアプリ内ブラウザで表示するため、13 歳未満を含めると Families ポリシー(子ども向けコンテンツ・広告・外部リンクの制約)の対象になる)。
- レーティングアンケートでは、ユーザー生成コンテンツ・広告なし、外部リンク(Wikipedia / YouTube / Wikimedia Commons)ありとして回答する。

## 知的財産・出典
- 写真: Wikimedia Commons の自由ライセンス画像のみ。CC BY / CC BY-SA の帰属表示要件はアプリ内(詳細カード・全画面表示・写真の出典一覧)と `docs/CREDITS.md` で満たす。
- 解説: Wikipedia(CC BY-SA 4.0)の記事冒頭の要約。本文は同梱しない。
- 分類・評価: Wikidata(CC0)。IUCN レッドリストのデータそのものは同梱しない(IUCN のデータは商用利用に制限があるため、Wikidata 経由のカテゴリ値のみ使用)。
- 地図: NASA Blue Marble(パブリックドメイン)。
- アプリ名・アイコンは他社の商標を使用していない。applicationId はリポジトリ名(`animal_planet`)ではなく中立な `io.github.hatake716.endangeredglobe` にしている(「Animal Planet」は同分野の登録商標で、公開後は変更できないため)。
