# プロモーション動画(プレビュー動画)

Google Play のストア掲載情報に登録する紹介動画です。**Play は動画ファイルを直接受け付けず、YouTube の URL のみ**を登録できます
([ヘルプ](https://support.google.com/googleplay/android-developer/answer/9866151))。以下の手順で YouTube に上げてから URL を登録してください。

| 項目 | 内容 |
|---|---|
| ファイル | `dist/play-v1.0.3/promo_1080x1920.mp4`(Git 管理外) |
| 長さ | 29.8 秒(自動再生される 30 秒に収めています) |
| 解像度 | 1080×1920(9:16 縦型)、30fps、H.264 |
| 音声 | なし(Play の自動再生はミュートのため、音声なしでも成立する構成) |
| 内容 | エミュレータ実機画面の録画。冒頭 1.6 秒のタイトル以外はすべてアプリの実画面 |

## YouTube へのアップロード時の設定(Play の要件)

- **収益化をオフ**にする(広告が表示される動画は使用不可)。
- 公開設定は**「一般公開」または「限定公開」**。「非公開」は不可。
- **年齢制限を設定しない**。
- **埋め込みを許可**する(詳細設定 → 埋め込みを許可)。
- タイトル・説明にも「今すぐダウンロード」等の行動喚起や、順位・評価・価格の表現を入れない。

### 推奨するタイトル・説明(例)

```
地球儀で見る絶滅危惧種生物図鑑 — アプリ紹介
```

```
IUCN レッドリストで絶滅のおそれがあると評価された動物 1,063 種を、3D 地球儀の上に代表的な生息地のピンとして配置した Android アプリの紹介です。ピンをタップすると写真・解説・生息環境・主な脅威が表示され、生物の分類と生息地で絞り込めます。

写真は Wikimedia Commons の自由ライセンス画像、解説は Wikipedia、分類と評価は Wikidata、地球画像は NASA Blue Marble(パブリックドメイン)です。
```

## Play Console への登録

1. 「ストアの掲載情報 → グラフィック → プレビュー動画」に YouTube の URL を入力する。
2. URL は `https://www.youtube.com/watch?v=VIDEO_ID` の形式にする。再生リスト・チャンネルの URL は不可。
   **タイムコード(`&t=`)などのパラメータを付けない。**
3. 保存後、掲載情報のプレビューで再生できることを確認する。

## 動画の作り直し

`docs/play/video/` に録画・編集のスクリプトを置いています。

```bash
# 1. 専用エミュレータを起動し、対象アプリだけを入れておく(他アプリが前面に出ると録画が中断される)
# 2. 操作を録画する。demo.sh は adb で操作しつつ、シーンの境目を marks.txt に書き出す
adb -s emulator-5560 shell screenrecord --size 1080x2400 --bit-rate 16M /sdcard/rec.mp4 &
bash docs/play/video/demo.sh 2> marks.txt
adb -s emulator-5560 pull /sdcard/rec.mp4 rec_raw.mp4

# 3. 可変フレームレートのままだと切り出しの尺が合わないので 30fps へ正規化する
ffmpeg -i rec_raw.mp4 -vf fps=30 -c:v libx264 -crf 18 -an rec_cfr.mp4

# 4. 字幕を焼き込んで連結する(rec_cfr.mp4 と marks.txt を同じディレクトリに置く)
python3 docs/play/video/build_video.py
```

`build_video.py` の `clips` を編集すると、切り出す区間と字幕を変えられます。
`demo.sh` の座標はエミュレータの 1080×2400 に合わせてあるので、画面サイズを変えたら取り直してください。
