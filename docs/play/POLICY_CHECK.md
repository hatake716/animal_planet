# Google Play 要件との照合(2026-09-06 時点)

エージェントが Google Play Console ヘルプを確認して作成した要件一覧と、このアプリの現状との差です。ヘルプの内容は変わることがあるので、提出時に再確認してください。

## 現状との差・対応

- **1. スクリーンショット(docs/images/01_globe.png〜06_photo.png)**: 6 枚とも 1080×2400(縦横比 2.22:1)で、Play の「最大辺は最小辺の 2 倍以下」規則に違反し、さらにアルファ付き 32-bit PNG(規定は JPEG または 24-bit PNG、アルファなし)。docs/PLAY_STORE.md 36 行目はこのセットを提出用とし「320〜3840px の範囲で受理」とだけ書いており、2 倍規則とアルファ規定が抜けている。
  - 対応: 提出には docs/play/screenshots/01〜07(1080×2160、24-bit RGB、7 枚)を使う(SUBMISSION.md は既にこちらを指している)。PLAY_STORE.md 36 行目と提出前チェックの記述を docs/play/screenshots に統一し、「最大辺は最小辺の 2 倍以下」「24-bit PNG(アルファなし)」を追記する。おすすめ枠(大判プロモーション)に載せたい場合は 9:16(1080×1920 以上)で 4 枚以上を別途用意する(例: 1080×2160 を 1080×1920 にトリミング/リサイズ)。docs/images は README 用として残してよい。
- **6. プライバシーポリシーのアプリ内リンク**: User Data ポリシーは全アプリに「Play Console の指定欄」と「アプリ内(リンクまたは本文)」の両方でのプライバシーポリシー掲載を求めているが、app/src/main/kotlin と res を grep しても「privacy」「プライバシー」が一切なく、AboutDialog.kt にもリンクがない。
  - 対応: AboutDialog.kt の「ライセンス」節の下などに「プライバシーポリシー」の TextButton(または URL テキスト)を追加し、https://hatake716.github.io/animal_planet/PRIVACY/ を既存の WebScreen(onOpen)か Intent.ACTION_VIEW で開く。あわせて PLAY_STORE.md の「プライバシーポリシー」節と提出前チェックに「アプリ内リンクあり」を追記する。
- **8. docs/CREDITS.md の種名が 1 行ずつずれている**: docs/CREDITS.md の「種」列が写真とずれている(例: 1 行目「イリナキウサギ」に Oryctolagus cuniculus(アナウサギ)の写真、2 行目「アナウサギ」に Pentalagus furnessi(アマミノクロウサギ)の写真)。原因は tools/assemble.py 112 行目で credits.append(... "name": name ...) を実行した後の 117 行目で name = it["name"] を代入しているため、各クレジットに前のループの種名が入る。species.json の写真対応(イリナキウサギ=写真なし、アナウサギ=Oryctolagus cuniculus)とアプリ内 CreditsScreen(catalog.entries から生成)は正しいので、影響は CREDITS.md と credits.json のみ。ただし PLAY_STORE.md / SUBMISSION.md は審査対応の権利証拠として docs/CREDITS.md を挙げており、一目で誤りとわかる表は証拠として逆効果。
  - 対応: tools/assemble.py で credits.append を name 確定後(117〜125 行目の後)に移すか、"name": it["name"] にする。その後 assemble.py → tools/make_credits.py credits.json docs/CREDITS.md を再実行して CREDITS.md を再生成し、1 行目が「アナウサギ | Oryctolagus cuniculus Tasmania.jpg」になることを確認する。
- **3. 製品版公開前のクローズドテスト要件**: 2023-11-13 以降に作成した個人デベロッパーアカウントは、製品版アクセス申請前に 12 人以上のテスターが 14 日連続でオプトインしたクローズドテストが必須だが、PLAY_STORE.md の提出前チェックと SUBMISSION.md のリリース手順は「内部テスト → 製品版」のみで、この要件に触れていない(アカウントの種別・作成日は未確認)。
  - 対応: アカウントが該当する場合は、SUBMISSION.md の「5. リリース」に「クローズドテスト(テスター 12 人以上・14 日連続)→ 製品版アクセス申請 → 製品版」を追加し、PLAY_STORE.md のチェックリストにも項目を足す。有料アプリでもテスターは無料で入手できるので、クローズドテスト期間中に価格設定と販売国を済ませておく。
- **3./2. 提出用ドキュメントの参照切れ**: docs/play/SUBMISSION.md は掲載文を docs/play/LISTING.md、申告フォームの回答を docs/play/FORMS.md に置くとしているが、docs/play には SUBMISSION.md・icon_512.png・feature_1024x500.png・screenshots/ しかなく、両ファイルが存在しない。掲載文の唯一の実体は PLAY_STORE.md にある。
  - 対応: PLAY_STORE.md の掲載文(アプリ名・簡単な説明・詳しい説明・新機能)を docs/play/LISTING.md に、データセーフティ/コンテンツレーティング/対象ユーザー/アプリのアクセス権/広告の回答を docs/play/FORMS.md に切り出して作成するか、SUBMISSION.md の参照を PLAY_STORE.md に書き換える。
- **4. コンテンツレーティング(IARC)の設問**: PLAY_STORE.md は「外部リンク(Wikipedia / YouTube / Wikimedia Commons)ありとして回答する」としているが、IARC アンケートの具体的な設問文(外部ウェブコンテンツ・ブラウザ機能に関する設問の有無と文言)は Play ヘルプから確認できなかった(未確認)。
  - 対応: Play Console で実際のアンケートを開き、設問文に沿って回答する。回答内容(特に「ユーザー間の交流」「位置情報共有」「デジタル購入」「その他」欄)を FORMS.md に記録し、WebView で外部サイトを開く機能を変更した場合は再回答する。
- **6. プライバシーポリシーの連絡先**: 問い合わせ手段が GitHub Issues のみ。ポリシーの「開発者の連絡先または問い合わせ手段」は満たすが、Play Console に登録するデベロッパーのメールアドレスとは別経路になっている。
  - 対応: 任意: docs/PRIVACY.md と docs/PRIVACY/index.html の「お問い合わせ」に Play Console に登録するサポート用メールアドレスも併記し、掲載情報の連絡先と一致させる。
- **8. YouTube ページの WebView 表示**: Play ポリシー上は「主目的が他サイトの webview」でなければ問題ないが、m.youtube.com の検索結果ページをアプリ内 WebView で表示することが YouTube の利用規約・ブランドガイドラインで許容されるかは Play ヘルプでは確認できない(未確認)。
  - 対応: 公開前に YouTube の利用規約を確認する。懸念が残る場合は「動画」ボタンを外部ブラウザ/YouTube アプリへの Intent(ACTION_VIEW)に切り替える(WebScreen.kt には既に「ブラウザで開く」処理があるため流用可)。
